# 林炯汉 · 个人作品集

一个以杂志式排版风格呈现的个人作品集网站，展示作者的软件工程学习经历与个人项目。

## 项目简介

本站为纯静态站点，通过数据驱动的方式渲染项目作品。所有项目内容集中在数据文件中维护，页面结构、分类筛选按钮、技术栈展示等均由脚本自动生成，新增/调整项目只需修改数据即可，无需改动页面代码。

## 技术栈

- **原生 HTML + CSS + JavaScript**：不使用任何前端框架与第三方 UI 组件库
- **CSS 变量**：集中管理设计色板，并支撑深浅主题切换
- **LocalStorage**：持久化记录用户的主题偏好
- **图片**：由 AI 生成（trae-api 文本生图接口）的杂志风格配图

## 运行方式

本项目无需构建，无依赖安装，直接用浏览器打开 `index.html` 即可。

- 直接双击 `index.html`，或在项目目录下用任意静态服务器启动（如 `npx serve`）。
- 页面文本内容已内嵌在 HTML 中，无需后端接口。

## 主要功能

- **数据驱动项目渲染**：5 个示例项目定义于 `js/data.js` 的 `PROJECTS` 数组，编号、分类按钮、技术栈、标签、展开说明均由 `js/main.js` 自动生成；新增项目只需在数组末尾追加对象。
- **四种杂志式版型**：支持 feature（大图主打）、split（左右对半并左右交替）、banner（全宽横图压字）、stack（小图长文）四种布局，混排营造杂志翻页节奏。
- **项目分类筛选**：按大类筛选项目，筛选后自动连续重新编号，并显示当前分类作品数量。
- **深/浅主题切换**：导航栏右侧提供主题切换按钮，配色基于 CSS 变量实时联动（背景、文字、边框同步变化），选择通过 LocalStorage 记忆，刷新不丢失、深色刷新无闪白。
- **吸顶导航 + 滚动高亮**：滚动时导航栏吸顶并显示阴影，当前阅读区块在导航中自动高亮。
- **滚动显现动画**：各区块进入视口时渐显上移，尊重系统的"减少动态效果"（prefers-reduced-motion）设置。
- **移动端适配**：导航折叠为汉堡菜单，多栏布局退化为单列，适配手机端浏览。
- **项目详情展开**：每个项目可展开查看补充设计说明，分组展示，交互流畅。
